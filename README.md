About the Project

This is a DBMS Cornerstone Project that implements a database for an E-Commerce Order Management System. It manages customer information, product details, categories, carts, orders, payments, deliveries, and reviews using a relational database.

Objectives
Store customer, product, and order data in one centralized system.
Manage cart, order, payment, and delivery information efficiently.
Reduce data redundancy through normalized table design.
Maintain data integrity using PRIMARY KEY, FOREIGN KEY, CHECK, UNIQUE, NOT NULL, and DEFAULT constraints.
Retrieve and analyze data using SQL queries, joins, aggregate functions, and views.
